# 🚀 JavaScript Final Assessment 🌟

👩‍💻✨ This repository contains a complete collection of code and solutions for various JavaScript learning modules, ranging from programming fundamentals, clean code style, OOP, recursion, to comprehensive unit testing and real-world scenarios.

> 📜 **Certification Context:** This project was developed as the final submission for the **JavaScript Programming Fundamentals** class in the **Dicoding** program.

## 📁 Project Structure & Modules 🗂️

Here is the list of modules and assessments included in this repository:

1. **`01-writing-comments`** 💬
    * **Description**: Assessment on writing single-line and multi-line comments in JavaScript.


    * **Main Files**: `index.js`, `instruksi.md`.




2. **`02-code-style`** ✨
    * **Description**: Assessment on refactoring code to adhere to consistent coding style guidelines (semicolons, 2-space indentation, `const` usage, and object property spacing).


    * **Main Files**: `index.js`, `instruksi.md`.




3. **`03-writing-test`** 🧪
    * **Description**: Assessment on writing unit tests for a basic `sum` function using built-in modules (`node:test` and `node:assert`).


    * **Main Files**: `index.js`, `index.test.js`, `instruksi.md`, `package.json`.




4. **`optional-04-oop`** 📦
    * **Description**: Object-Oriented Programming assessment to build an inventory management system using ES6 classes (`Item` and `Inventory`).


    * **Main Files**: `Item.js`, `Inventory.js`, `main.js`, `instruksi.md`, `package.json`.




5. **`optional-05-recursive`** 🔄
    * **Description**: Assessment on implementing recursive functions to calculate factorials and generate Fibonacci sequences up to the $n$-th element.


    * **Main Files**: `factorial.js`, `fibonacci.js`, `main.js`, `instruksi.md`, `package.json`.




6. **`optional-06-full-coverage-testing`** 🎯
    * **Description**: Comprehensive full-coverage unit testing assessment for a `sum` function handling edge cases, invalid data types, and negative numbers.


    * **Main Files**: `index.js`, `index.test.js`, `instruksi.md`, `package.json`.




7. **`optional-07-real-world-scenario`** 🍔
    * **Description**: Real-world scenario application for a Restaurant Order Management System utilizing arrays, objects, unique ID generation, status updates, total revenue calculation, and order filtering.


    * **Main Files**: `main.js`, `orders.js`, `instruksi.md`, `package.json`.

## 🛠️ How to Run the Project & Tests 💻

1. Make sure **Node.js** is installed on your device ⚙️.
2. Navigate into one of the module directories that contains a `package.json` file (e.g., `optional-06-full-coverage-testing` or `03-writing-test`):
    ```bash
    cd optional-06-full-coverage-testing

    ```


3. Run the script or test files using Node.js:
    ```bash
    node index.test.js
    # or
    node main.js

    ```
